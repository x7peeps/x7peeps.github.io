## 一、执行摘要

**Akira** 是近年来崛起最快的勒索软件即服务（RaaS）组织之一，于2023年3月首次被发现。该组织被认为与已解散的 **Conti** 勒索组织有密切联系，其名称源自1988年日本动画电影《阿基拉》。截至2026年6月，Akira 已攻击超过 **1,400 个组织**，累计勒索金额约 **2.44-2.45 亿美元**，成为全球最活跃、获利最高的勒索软件组织之一。

<!--more-->

### 关键发现

| 维度 | 关键指标 |
|------|----------|
| **组织规模** | 1,400+ 受害者，2.44亿美元+勒索金额 |
| **攻击速度** | 从初始入侵到完全加密最短仅需 **1小时**，通常不超过4小时 |
| **加密强度** | ChaCha20 + RSA-4096，**有解密器**（Avast，仅限早期 Windows 变体） |
| **首要入口** | VPN 漏洞利用（Cisco ASA/AnyConnect、SonicWall、Fortinet） |
| **商业模式** | RaaS，20万美元-数百万美元赎金 |
| **加密器变体** | Akira（C++）、Akira_v2（Rust）、Megazord（Rust） |
| **多平台支持** | Windows、Linux、VMware ESXi、Hyper-V、Nutanix AHV |
| **洗钱策略** | 四阶段演化，与 Fog/Frag 共享基础设施 |
| **解密可能性** | **部分存在**（Avast 解密器适用于早期 Windows 变体，新版/v2 及 Linux 变体暂无解密工具） |

## 四、技术能力评估

### 4.1 恶意软件演变

| 阶段 | 时间 | 语言 | 特征 |
|------|------|------|------|
| **Akira（原始版）** | 2023年3月 | C++ | 最初版本，Windows 平台 |
| **Akira_v2** | 2023年8月 | Rust | 改进版，针对性更强 |
| **Megazord** | 2023年8月 | Rust | `.powerranges` 扩展名，2024年后逐渐弃用 |

### 4.2 加密机制分析

#### 4.2.1 加密算法

| 组件 | 算法 | 说明 |
|------|------|------|
| **对称加密** | ChaCha20 | 流加密，速度快 |
| **非对称加密** | RSA-4096 | 加密 ChaCha20 密钥 |
| **密钥策略** | CryptGenRandom | Windows API 生成随机数 |
| **文件扩展名** | `.akira`、`.powerranges` | 版本标识 |

#### 4.2.2 加密流程

```
┌─────────────────────────────────────────────────────────────┐
│  1. 使用 CryptGenRandom 生成对称密钥                        │
│  2. 使用 ChaCha20 加密文件内容                              │
│  3. 生成 RSA-4096 密钥对                                    │
│  4. 使用 RSA-4096 公钥加密 ChaCha20 密钥                      │
│  5. 将加密后的对称密钥与受害者 ID 写入文件头部                │
│  6. 重命名文件（追加 .akira / .powerranges 扩展名）           │
│  7. 投放 HOW_TO_RECOVER_DATA 勒索信（HTML + TXT 双格式）      │
│  8. 删除卷影副本、修改桌面壁纸，注册表启动项保活              │
└─────────────────────────────────────────────────────────────┘
```

#### 4.2.3 平台差异

Windows 版走 ChaCha20+RSA 混合加密；ESXi 版则是独立实现的加密器，直接针对 VMFS 数据存储批量加密虚拟机磁盘文件——在虚拟化层"一锅端"，这是 Akira 长期偏爱攻击 VMware 环境托管服务商与 MSP 的原因。此外 Akira 惯常在加密前先部署 BitLocker 封锁恢复路径，进一步抬高恢复成本。

## 六、执法处置与组织现状

2025 年 4 月，欧洲刑警组织牵头的 **Operation Endgame** 联合 17 国执法与私营部门力量摧毁 Akira 基础设施：查扣 145 个域名与约 300TB 数据，英国 NCSC 同步指出其加密强度"此前难以破解"，联合行动还交付了配套的 BitLocker 解密工具。此后泄密站于 2025 年中被关闭，但仿冒".akira"品牌的团伙层出不穷，残余 affiliate 持续向其他勒索品牌流动。

## 七、防御建议

1. RDP/VPN 全面 MFA + 爆破与异常登录告警；
2. 对 BitLocker 部署、卷影副本删除、勒索信落地三类行为配置实时响应剧本；
3. 备份遵循 3-2-1 + 不可变副本，虚拟化平台管理面独立组网；
4. 合法远程工具（AnyDesk、ConnectWise 等）建立白名单审批与使用审计。

## 八、总结

Akira 的画像是"低调但高效"：不搞泄密站营销噱头，靠加密器工程质量与 ESXi 专项能力吃下大量 MSP 与托管服务商客户。Operation Endgame 证明这种结构化勒索品牌的基础设施可以被连根拔起——但只要弱 MFA、旧暴露面这些初始访问的温床还在，替代品牌就会永远在注册新域名的路上。技术防御的尽头，仍然是暴露面治理。
