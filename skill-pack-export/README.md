# x7peeps Article Skills Pack

这个目录包含 5 个可独立分发的 Skill 包，每个子目录均可作为一个标准 Skill 使用。

## 包含内容

- `x7-ai-article-writer`
- `x7-product-page-writer`
- `x7-vuln-research-writer`
- `x7-redteam-article-writer`
- `x7-blueteam-article-writer`

## 与原始用途对应关系

- `个人主页-文章编写-AI方向` -> `x7-ai-article-writer`
- `个人主页-文章编写-产品页面` -> `x7-product-page-writer`
- `个人主页-文章编写-漏洞研究` -> `x7-vuln-research-writer`
- `个人主页-文章编写-红队文章编写` -> `x7-redteam-article-writer`
- `个人主页-文章编写-蓝队文章编写` -> `x7-blueteam-article-writer`

## 结构

每个 Skill 包目录都只有一个必须文件：

```text
<skill-dir>/
  SKILL.md
```

## 说明

- 这些 Skill 已按可复用原则重写，避免包含任务性、一次性或敏感内容。
- 如需继续增强，可在对应 `SKILL.md` 中追加你的工作流、模板或站点 frontmatter 约束。
