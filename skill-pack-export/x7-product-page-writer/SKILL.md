# x7peeps 产品页写作

本技能用于为个人站点编写产品展示页面内容，适合 App、SaaS、工具站、浏览器插件、AI 产品、桌面软件等产品型内容。

## 何时调用

- 用户要求“新增一个产品页”
- 用户想展示某个 App、工具或软件产品
- 用户只有零散素材，希望整理成可发布的产品介绍页面
- 用户需要同时补齐隐私政策、FAQ、功能说明等配套文案

## 目标

- 把零散的产品信息整理成结构完整的产品页面内容
- 强调受众、问题场景、核心价值、功能卖点和使用路径
- 保证页面既适合对外展示，也方便后续做 SEO 和转化

## 工作流

1. 先获取产品基础信息：名称、定位、目标用户、解决的问题、平台、收费方式、上线状态。
2. 梳理核心卖点，避免把功能列表直接堆成页面。
3. 生成页面结构，通常包括 Hero、问题场景、能力亮点、使用流程、FAQ、CTA。
4. 如果用户信息不足，主动补问最关键缺口，而不是直接编造产品能力。
5. 如果用户要落站点页面，尽量同时提供标题、副标题、短描述、SEO 描述。
6. 若涉及合规内容，补充隐私政策、数据收集说明、联系方式等基础模块。

## 推荐页面结构

```markdown
# 产品名称

## 一句话价值主张
## 适合谁
## 解决什么问题
## 核心功能
## 使用方式
## 常见问题
## 隐私与数据说明
## 行动引导
```

## 写作要求

- 首屏必须让用户一眼看懂“这是什么、给谁用、为什么值得试”
- 卖点写“收益”，不要只写“有某个按钮或某个功能”
- 术语少而准，不要把产品页写成技术白皮书
- CTA 要清晰，例如“立即体验”“查看演示”“下载试用”
- 如果产品尚未发布，文案要如实体现状态，不要暗示已商用

## 配套输出

- 产品页完整 Markdown
- Hero 标题与副标题候选
- SEO title / description 建议
- FAQ 草案
- 隐私政策草案

## 特别注意

- 如已有站点模板或历史产品页，先对齐语气、结构和字段命名。
- 如果产品面向海外或双语用户，可追加英文短版文案，但不要默认双语。
- 对任何未确认的信息使用占位提醒，不要虚构用户案例、下载量或客户名单。
