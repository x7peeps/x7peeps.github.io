# x7peeps 蓝队文章写作

本技能用于产出蓝队与防守运营方向文章，适合日志分析、应急响应、检测规则、溯源复盘、漏洞缓解、威胁情报与安全运营主题。

## 何时调用

- 用户要求“写一篇蓝队文章”
- 用户要整理某次事件响应、取证或检测经验
- 用户希望沉淀漏洞防御、告警分析、威胁狩猎类专题
- 用户要规划面向防守团队的系列内容

## 目标

- 让文章对防守侧读者有直接行动价值
- 不只解释原理，还要给出排查、检测、修复与运营建议
- 保持过程清晰，方便复盘与二次复用

## 工作流

1. 先确认文章类型：事件复盘、检测方法、威胁分析、漏洞缓解还是取证专题。
2. 提炼读者最关心的问题，例如“怎么发现”“怎么确认”“怎么止血”“怎么复盘”。
3. 先写信号来源和判断依据，再写处置动作。
4. 如果是事件型文章，按时间线梳理发现、分析、定位、处置、修复和复盘。
5. 如果是方法型文章，按数据源、规则逻辑、误报边界、落地建议来组织。
6. 结尾补充检查清单、经验教训和后续改进项。

## 推荐结构

```markdown
# 标题

## 背景与目标
## 发现线索
## 分析过程
## 定位与确认
## 处置与缓解
## 检测优化建议
## 复盘与经验总结
```

## 写作要求

- 以证据链驱动叙述，不要只写结论
- 检测与分析步骤要尽量可复用
- 明确指出误报来源、边界条件和适用前提
- 如果涉及威胁归因，区分事实证据与分析判断
- 对防守建议尽量给到可执行动作，而不是空泛口号

## 配套输出

- 蓝队正文 Markdown
- 摘要与标签建议
- 检查清单 / 排查要点
- 可选：管理层摘要版要点

## 特别注意

- 如果文章基于真实事件，要先去除敏感信息和不可公开细节。
- 如果主题偏取证，优先保留时间线、关键证据、分析方法和结论依据。
- 如果用户要求批量规划，先按“检测类 / 复盘类 / 情报类 / 漏洞缓解类”给出选题池。
