# x7peeps 红队文章写作

本技能用于生成红队与渗透测试方向的研究文章，适合边界设备、企业应用、中间件、邮件系统、身份认证、横向移动前置路径等内容。

## 何时调用

- 用户要求“写一篇红队文章”
- 用户希望沉淀某类攻击面的打法总结
- 用户要按批次规划红队专题
- 用户已有利用链或实战经验，希望整理为可发表内容

## 目标

- 把攻击面、利用条件、突破路径和限制条件讲清楚
- 让文章兼具方法论价值与可读性，而不是流水账
- 对外表达时保持边界感，不输出不必要的高风险操作细节

## 工作流

1. 先确定攻击面与受众：是面向入门、面向实战，还是面向专题复盘。
2. 梳理文章主线：资产识别 -> 薄弱点 -> 进入点 -> 提权/横向/持久化前置条件。
3. 如果是具体产品或组件，先写环境背景和典型部署方式。
4. 如果是打法总结，优先抽象出可迁移的方法，而不是只写单一案例。
5. 用步骤化结构表达攻击路径，但避免直接贴危险 payload 集合。
6. 收尾补充检测思路、缓解建议和适用边界。

## 推荐结构

```markdown
# 标题

## 场景背景
## 攻击面与入口
## 关键利用思路
## 路径拆解
## 约束条件与失败点
## 防守建议
## 总结
```

## 写作要求

- 重点突出“为什么这条路径成立”
- 明确区分前提条件、可选路径和最终效果
- 尽量用攻击链视角组织内容，而非散点知识罗列
- 不夸大战果，不把实验室场景误写成通杀实战方案
- 对高风险细节做适度抽象，保留研究价值即可

## 配套输出

- 红队研究正文 Markdown
- 文章摘要
- 专题标签与系列标题建议
- 可选：同主题下一篇文章候选

## 特别注意

- 如文章服务于系列化内容，优先保证标题体系、攻击阶段命名和术语一致。
- 如果材料来自多个真实案例，先抽象共性，再补个别差异。
- 如用户同时需要图示，可额外生成攻击路径大纲，供后续绘图或配图使用。
